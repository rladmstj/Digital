다음과 같은 2종류의 스크립트를 만들고자 한다.
get_morphs_tags.py : 주어진 형태소 분석 파일로부터 모든 형태소와 품사를 추출한다.
tagged2context.py : 주어진 형태소 분석 파일로부터 색인어를 추출하여 문맥 파일을 생성한다.

1. 형태소 분석 결과로부터 형태소와 품사를 추출하는 함수(get_morphs_tags)를 작성하여 get_morphs_tags.py를 완성한다.
2. 색인어를 추출하는 함수(get_index_terms)를 작성하여 tagged2context.py를 완성한다.
   완성된 스크립트의 실행 방법은 다음과 같다.
   $ ./get_morphs_tags.py 입력파일 > 출력파일
   예) $ ./get_morphs_tags.py all.tag > all.mt
   $ ./tagged2context.py 입력파일(s)
   예) ./tagged2context.py \*.tag
   각 입력파일에 대해 "입력파일.context"라는 출력 파일이 생성됨

- 형태소와 품사를 추출할 때 유의할 점

  - 어절 내 '+'나 '/' 문자가 있는 경우에 대한 처리

  - 품사태그의 유효성은 검사할 필요없음

- 색인어를 추출할 때 유의할 점
  - 색인 대상 형태소는 다음의 품사임
    NNG(일반명사), NNP(고유명사), NR(수사), NNB(의존명사), SL(외국어; 영어), SH(한자), SN(숫자)
  - 색인어는 단일어 뿐만 아니라 복합어도 추출해야 함
    여기서, 복합어란 동일한 어절 내에서 연속된 색인 대상 형태소들의 결합형을 의미함
  - 동일한 어절에 단일어와 복합어가 함께 나타나는 경우,
    출력 순서는 단일어들을 먼저 출력한 후 복합어를 출력해야 함
  - 셋 이상의 단일어가 연속되는 경우 가장 긴 복합어만 출력함
    예) 정부/NNG+조직/NNG+개편/NNG -> 정부 조직 개편 정부조직개편
  - NNG, NNP, SH, SL은 단일어로도 색인어로 추출함 (단, SL이 복합어에 속하는 경우 단일어로는 색인어로 추출하지 않음)
  - NR, NNB, SN은 단일어로는 색인어로 추출하지 않음
    예) ５대 ５/SN+대/NNB -> ５대
    Y2K위원회 Y/SL+2/SN+K/SL+위원회/NNG -> 위원회 Y2K위원회
    SK텔레콤처럼 SK/SL+텔레콤/NNG+처럼/JKB -> 텔레콤 SK텔레콤
- 첨부파일에 다음의 파일들을 첨부함
  - 두 스크립트에 대한 실행 결과 (all.mt, all.tag.context)
  - 형태소 분석 코퍼스 (all.tag)
