1. 연도별 문맥 파일들로부터 연도별 단어 빈도(.1gram), 공기어 빈도(.2gram), 단어 문맥 크기(.1gram_context) 파일을 생성하는 coword_frequency.py를 작성한다. (코퍼스 분석 로드맵.pptx p.26 참고)

완성된 스크립트의 실행 방법은 다음과 같다.

$ ./coword_frequency.py 입력파일(s)
예) $ ./coword_frequency.py *.context

* 출력 파일은 각 연도별 .1gram, .2gram, .1gram_context이 생성됨

* .1gram과 .1gram_context 파일의 출력 형식은 다음과 같음
단어\t빈도

* .1gram 파일의 첫 줄에는 #Total에 대한 빈도가 있어야 함

* .2gram 파일의 출력 형식은 다음과 같음
대상어\t공기어\t빈도

* 같은 문맥에 2번 이상 반복 출현하는 단어는 1번 나타난 것으로 간주함 (팁: 중복제거를 위해 집합(set)으로 변환)
  단어 빈도(1gram)와 문맥 크기(1gram_context)도 중복을 무시하고 계산함

* 대상어와 공기어 쌍은 문자열 정렬 기준에 따라 한번만 출력함 예) "A B 빈도"는 출력하나 "B A 빈도"는 출력하지 않음

* 모든 출력 파일은 문자열 기준으로 정렬되어야 함

2. 단어 빈도(.1gram), 공기어 빈도(.2gram), 단어 문맥 크기(.1gram_context) 파일로부터 공기어 t-점수를 계산하는 calc_co-oc_tscore.py를 작성한다. (코퍼스 분석 로드맵.pptx p.27 참고)

완성된 스크립트의 실행 방법은 다음과 같다.

$ ./calc_co-oc_tscore.py 입력파일(s)
예) $ ./calc_co-oc_tscore.py *.2gram

* 출력 파일은 각 연도별 .tscore가 생성됨

* .tscore 파일의 출력 형식은 다음과 같음
대상어\t공기어\tt-점수

* 제약 사항

- t-점수가 양수인 경우만 출력함

- t-점수는 소수 3째자리까지 출력 ("%.3f"%변수명 또는 f"{변수명:.3f}"사용)

- 공기빈도가 CUTOFF(= 5) 이상인 경우만 t-점수를 계산함

- 대상어가 공기어를 포함하는 경우는 출력하지 않음
  예) 개인정보/정보 *, 교육부장관/장관 *, 인사청문회/청문회 *

* 출력 파일은 문자열 기준으로 정렬되어야 함 (sorted 함수 사용)

* 첨부파일에 다음의 파일들을 첨부함 (결과 비교용)
  - 연도별 문맥 파일 (2000.tag.context ~ 2019.tag.context)
  - 연도별 출력 파일 (2000~2019.1gram, 2000~2019.2gram, 2000~2019.1gram_context)
  - 연도별 공기어 t-점수 파일 (2000.tscore ~ 2019.tscore)
